1.2 Exercício Etapa 1: Idade Fixo no Ano de 2026

Nesta primeira etapa, o usuário informa o seu ano de nascimento e o script calcula quantos anos ele completará ou completou no ano de 2026.

idade_2026.php 
<?php
$idade2026 = null;
if ($_SERVER["REQUEST_METHOD"] == "POST" && isset($_POST["ano_nascimento"])) {
    $anoNascimento = (int)$_POST["ano_nascimento"];

1.4 Exercício Etapa 3: Cálculo da Idade Exata (Dia, Mês e Ano)

Apenas subtrair o ano não considera se a pessoa já fez aniversário no ano corrente. Usamos a classe DateTime para calcular o intervalo de tempo exato em anos, meses e dias.

idade_exata.php 
<?php
$resultadoExato = null;

if ($_SERVER["REQUEST_METHOD"] == "POST" && !empty($_POST["data_nascimento"])) {
    $dataNasc = new DateTime($_POST["data_nascimento"]);
    $hoje = new DateTime(); // Data e hora atual
    $diferenca = $hoje->diff($dataNasc);

    $resultadoExato = [
        'anos' => $diferenca->y,
        'meses' => $diferenca->m,
        'dias' => $diferenca->d
    ];
}
?>

<form method="POST" action="">

    <input type="date" name="data_nascimento" required>
    <button type="submit">Calcular Idade Exata</button>
</form>

<?php if ($resultadoExato): ?>
    <div class="result-box">
        <p>Idade exata hoje:</p>
        <ul>
            <li><strong><?php echo $resultadoExato['anos']; ?></strong> Anos</li>
            <li><strong><?php echo $resultadoExato['meses']; ?></strong> Meses</li>
            <li><strong><?php echo $resultadoExato['dias']; ?></strong> Dias</li>

Módulo 2

Variáveis Locais vs. Variáveis de Servidor ($_SERVER, $_SESSION, $_COOKIE)

Compreenda o escopo de variáveis em PHP e aprenda a capturar informações do ambiente e do usuário para criar ferramentas utilitárias úteis e reaproveitáveis.

2.1 Entendendo Escopo e Tipos de Variáveis

Em PHP, variáveis locais existem apenas dentro da função/bloco em que foram declaradas. Já as superglobais são variáveis pré-definidas pelo PHP acessíveis em qualquer ponto do código.

  • $variavelLocal: Declarada dentro de uma função ou arquivo específico.
  • $_SERVER: Armazena cabeçalhos, caminhos, IP e informações do servidor e cliente.
  • $_SESSION: Armazena dados persistentes no servidor enquanto a sessão do usuário durar.
  • $_COOKIE: Guarda informações enviadas pelo servidor no navegador do usuário.

2.2 Exercício Útil 1: Inspetor de Acesso do Cliente (Widget de Diagnóstico)

Crie uma ferramenta reaproveitável que identifica o IP do visitante, sistema operacional/navegador (User-Agent) e idioma preferido. Excelente para ser embutida no rodapé ou painel de qualquer sistema web.

inspetor_servidor.php 
<?php
function obterInfoCliente() {
    $ip = $_SERVER['REMOTE_ADDR'] ?? '127.0.0.1';
    $navegador = $_SERVER['HTTP_USER_AGENT'] ?? 'Desconhecido';
    $protocolo = $_SERVER['SERVER_PROTOCOL'] ?? 'HTTP/1.1';
    $metodo = $_SERVER['REQUEST_METHOD'] ?? 'GET';
    $idioma = $_SERVER['HTTP_ACCEPT_LANGUAGE'] ?? 'pt-BR';

    return [
        'ip' => $ip,
        'user_agent' => $navegador,
        'protocolo' => $protocolo,
        'metodo' => $metodo,
        'idioma' => $idioma
    ];
}

$info = obterInfoCliente();
?>

<div class="info-card">
    <h4> Diagnóstico de Acesso</h4>
    <p><strong>Seu IP:</strong> <?php echo $info['ip']; ?></p>
    <p><strong>Método de Requisição:</strong> <?php echo $info['metodo']; ?></p>
    <p><strong>Seu Navegador:</strong> <?php echo $info['user_agent']; ?></p>
</div>

2.3 Exercício Útil 2: Contador de Visitas com Sessão e Cookies

Aprenda a controlar quantas vezes o usuário visitou uma página utilizando $_SESSION para a sessão atual e $_COOKIE para guardar a última visita de forma persistente.

session_start();

// Incrementar contador de páginas acessadas na sessão
if (!isset($_SESSION['visitas_sessao'])) {

}

// Gravar cookie da última visita válida por 30 dias

?>

Gravação de Dados em Arquivos JSON & Mini CRUD

3.1 Como Manipular Arquivos JSON com PHP

O PHP possui funções nativas simples e poderosas para lidar com arquivos e o formato JSON:

  • json_encode($dados, JSON_PRETTY_PRINT): Converte um Array PHP para uma string formatada em JSON.
  • json_decode($jsonString, true): Decodifica uma string JSON para um Array associativo PHP.
  • file_get_contents('dados.json'): Lê todo o conteúdo do arquivo.
  • file_put_contents('dados.json', $jsonString): Salva o conteúdo no arquivo.
salvar_contato.php 
<?php
$arquivo = 'contatos.json';

// Inicializar arquivo se não existir
if (!file_exists($arquivo)) {
    file_put_contents($arquivo, json_encode([]));
}

if ($_SERVER["REQUEST_METHOD"] == "POST") {
    // Ler os dados existentes no arquivo JSON
    $conteudoAtual = file_get_contents($arquivo);
    $contatos = json_decode($conteudoAtual, true) ?? [];

    // Criar novo registro com ID único
    $novoContato = [
        'id' => uniqid(),
        'nome' => htmlspecialchars($_POST['nome']),
        'email' => htmlspecialchars($_POST['email']),
        'data_registro' => date('d/m/Y H:i')
    ];

    // Adicionar e salvar de volta no arquivo .json
    $contatos[] = $novoContato;
    file_put_contents($arquivo, json_encode($contatos, JSON_PRETTY_PRINT));
    echo "Contato salvo com sucesso!";
}
?>

3.2 Evoluindo para um Mini CRUD em JSON

Um CRUD básico necessita de 4 operações principais. Veja como implementar em PHP utilizando o arquivo `.json`:

mini_crud.php 
<?php
$arquivo = 'tarefas.json';
$tarefas = file_exists($arquivo) ? json_decode(file_get_contents($arquivo), true) : [];

// --- C: CREATE (Adicionar) ---
if (isset($_POST['acao']) && $_POST['acao'] === 'criar') {
    $nova = [
        'id' => time(),
        'titulo' => htmlspecialchars($_POST['titulo']),
        'concluida' => false
    ];
    $tarefas[] = $nova;
    file_put_contents($arquivo, json_encode($tarefas, JSON_PRETTY_PRINT));
}

// --- D: DELETE (Remover) ---
if (isset($_GET['deletar'])) {
    $idDeletar = $_GET['deletar'];
    $tarefas = array_filter($tarefas, fn($t) => $t['id'] != $idDeletar);
    file_put_contents($arquivo, json_encode(array_values($tarefas), JSON_PRETTY_PRINT));
}
?>

4.1 Tela de Login com Senha Criptografada em JSON

Atenção: Nunca salve senhas em texto puro! Em PHP, a função padrão recomendada para criptografar senhas com algoritmo seguro (BCrypt/Argon2) é a password_hash() e para verificar usaremos password_verify().

cadastro_e_login.php 
<?php
session_start();
$arquivoUsuarios = 'usuarios.json';

// --- CADASTRAR NOVO USUÁRIO ---
if (isset($_POST['acao']) && $_POST['acao'] === 'cadastrar') {
    $usuario = trim($_POST['usuario']);
    $senhaPura = $_POST['senha'];

    // Gerar HASH seguro da senha
    $senhaHash = password_hash($senhaPura, PASSWORD_DEFAULT);

    $usuarios = file_exists($arquivoUsuarios) ? json_decode(file_get_contents($arquivoUsuarios), true) : [];
    $usuarios[$usuario] = [
        'usuario' => $usuario,
        'senha_hash' => $senhaHash
    ];

    file_put_contents($arquivoUsuarios, json_encode($usuarios, JSON_PRETTY_PRINT));
    echo "Usuário cadastrado com sucesso e senha criptografada!";
}

// --- AUTENTICAR / LOGIN ---
if (isset($_POST['acao']) && $_POST['acao'] === 'login') {
    $usuario = trim($_POST['usuario']);
    $senhaPura = $_POST['senha'];

    $usuarios = file_exists($arquivoUsuarios) ? json_decode(file_get_contents($arquivoUsuarios), true) : [];

    if (isset($usuarios[$usuario]) && password_verify($senhaPura, $usuarios[$usuario]['senha_hash'])) {
        $_SESSION['usuario_logado'] = $usuario;
        echo "Login bem-sucedido! Bem-vindo, " . htmlspecialchars($usuario);
    } else {
        echo "Usuário ou senha inválidos!";
    }
}
?>

4.2 Consumindo uma API Pública de Previsão do Tempo em PHP

Integrar dados externos é uma habilidade fundamental. Usamos file_get_contents() ou a biblioteca cURL do PHP para consumir a API REST gratuita da Open-Meteo para previsão do tempo.

clima_api.php 
<?php
// Coordenadas de São Paulo
$latitude = -23.55;
$longitude = -46.63;
$apiUrl = "https://api.open-meteo.com/v1/forecast?latitude={$latitude}&longitude={$longitude}&current_weather=true";

// Fazer requisição GET para a API REST
$respostaJson = file_get_contents($apiUrl);

if ($respostaJson !== false) {
    $dadosClima = json_decode($respostaJson, true);
    $temperatura = $dadosClima['current_weather']['temperature'];
    $velocidadeVento = $dadosClima['current_weather']['windspeed'];

    echo "<h4>Previsão do Tempo em São Paulo</h4>";
    echo "<p>Temperatura atual: <strong>{$temperatura}°C</strong></p>";
    echo "<p>Velocidade do vento: {$velocidadeVento} km/h</p>";
} else {
    echo "Erro ao conectar com a API de clima.";
}
?>

Módulo 5

Projeto Integrador Final: Sistema CRUD Completo com JSON

Consolide todo o conhecimento do curso desenvolvendo um sistema completo com autenticação, listagem, cadastro, edição e exclusão de registros utilizando unicamente arquivos .json e PHP.

5.1 Especificações do Projeto Final

O aluno deverá construir um sistema completo (ex: Sistema de Gerenciamento de Alunos, Tarefas ou Produtos) respeitando a seguinte arquitetura:

  • index.php: Tela de login e redirecionamento.
  • dashboard.php: Painel principal com exibição dos dados lidos do arquivo JSON.
  • salvar.php: Lógica para Create (Criar) e Update (Editar) registros.
  • deletar.php: Lógica para Delete (Remover) registros.
  • banco.json: Arquivo JSON de armazenamento de registros.
  • usuarios.json: Arquivo JSON de usuários cadastrados com senha hash.

5.2 Estrutura e Código do Projeto Final Integrador

Abaixo está o modelo de código completo para a lógica de controle CRUD (Create, Read, Update, Delete) em JSON do projeto final:

sistema_crud_final.php 
<?php
session_start();

// Proteção de Acesso: Apenas usuários logados
if (!isset($_SESSION['usuario_logado'])) {
    header("Location: index.php");
    exit();
}

$arquivoDados = 'banco.json';

function carregarDados($arquivo) {
    if (!file_exists($arquivo)) return [];
    $conteudo = file_get_contents($arquivo);
    return json_decode($conteudo, true) ?? [];
}

function salvarDados($arquivo, $dados) {
    file_put_contents($arquivo, json_encode(array_values($dados), JSON_PRETTY_PRINT));
}

$registros = carregarDados($arquivoDados);

// --- CREATE & UPDATE ---
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $id = $_POST['id'] ?? null;
    $titulo = htmlspecialchars($_POST['titulo']);
    $descricao = htmlspecialchars($_POST['descricao']);

    if ($id) {
        // Atualizar existente (UPDATE)
        foreach ($registros as &$item) {
            if ($item['id'] == $id) {
                $item['titulo'] = $titulo;
                $item['descricao'] = $descricao;
                $item['atualizado_em'] = date('d/m/Y H:i');
                break;
            }
        }
    } else {
        // Criar novo registro (CREATE)
        $novo = [
            'id' => uniqid(),
            'titulo' => $titulo,
            'descricao' => $descricao,
            'criado_em' => date('d/m/Y H:i')
        ];
        $registros[] = $novo;
    }

    salvarDados($arquivoDados, $registros);
    header("Location: dashboard.php");
    exit();
}

// --- DELETE ---
if (isset($_GET['acao']) && $_GET['acao'] === 'deletar') {
    $idDeletar = $_GET['id'];
    $registros = array_filter($registros, fn($r) => $r['id'] !== $idDeletar);
    salvarDados($arquivoDados, $registros);
    header("Location: dashboard.php");
    exit();
}
?>
